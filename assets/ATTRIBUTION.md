# Artwork

- `DriverLoom-brand.png`: the user's supplied DriverLoom brand sheet. The title bar displays its original wordmark directly; the source sheet is unmodified.
- `DriverLoom-icon-source.png`: app tile prepared from the user's supplied sheet using the built-in imagegen edit tool. Prompt: "Faithfully extract ONLY the lower square app icon: the blue-to-purple linked double-o / infinity emblem centered within its original dark navy rounded-square tile and thin subtle border. Remove all surrounding background to transparent alpha and remove the upper DriverLoom wordmark. Output a square icon image ... no text, new symbols, embellishments or shadows outside the tile." The generated image was visually reviewed and stored in this project. `Build-BrandAssets.ps1` only resizes and encodes it into Windows icon sizes.
- `GitHub-light.png` and `GitHub-dark.png`: unmodified GitHub Invertocat PNGs from [GitHub's official logo bundle](https://brand.github.com/GitHub_Logos.zip), used only to link to the source repository. [GitHub brand guidance](https://brand.github.com/foundations/logo).
- Hardware category symbols and window controls are original vector drawing commands in `Theme.cs`. No manufacturer logo is inferred from an uncertain device identity.
