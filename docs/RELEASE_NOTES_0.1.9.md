# DriverLoom 0.1.9

- Removed the scan-summary text and vendor-update count above the device list.
- Reclaimed the empty space so the list sits directly below Your hardware.
- Added a saved Show unsupported devices checkbox in Settings, off by default.
- Added Open Windows Update and Copy list buttons to the unsupported-items and Windows Update exclusions pages.
- Added a Windows Update shortcut in Settings.

Unsupported devices and excluded offers remain available in Settings. Scan progress and failures appear in the footer, and available updates appear in the device list and Update All review.

The installer is unsigned while the signing setup is paused.
