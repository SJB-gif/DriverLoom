# DriverLoom 0.1.13

- Kept up-to-date devices in the list with secondary Vendor details links.
- Simplified successful comparisons to Up to date or Update available. An installed version above the checked source is shown as Up to date; the full comparison remains in device details.
- Failed or ambiguous comparisons show Check unavailable and never imply that a device is current.
- Default sorting is Device A–Z. Device supports A–Z/Z–A; Status uses updates first, then up-to-date devices, then application names A–Z, then unavailable checks. Devices within each group are alphabetical.
- Installed, Available and Action headers do not sort. The selected order is retained when results refresh.

Release publishing and signing remain on hold.
