# DriverLoom 0.1.12

- Device status now names the managing software or support page instead of showing a generic Vendor App badge. Long software names wrap within the status column.
- Settings has no close, save or cancel buttons. Click back onto the main window or press Esc to save and return. The dismissing click cannot also trigger a main-window action; invalid catalog entries remain open for correction.
- Removed the separate Other update methods button. The checkbox shows those devices and their official links in the main hardware list.
- Moved background options to the left and BIOS/firmware options to the right. Enabling BIOS checks also enables the USB guide immediately.
- Editing an individual device source preserves the other saved preferences.

Release publishing and signing remain on hold.
